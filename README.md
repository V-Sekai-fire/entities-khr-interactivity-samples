# entities-khr-interactivity-samples

Sample behavior graphs in the JSON form of the KHR_interactivity glTF extension, for testing graph runtimes and compilers.

## What it is for

Each file is a standalone graph that exercises one area of the extension: events, variables, pointers, flow control, delays, math, or unknown nodes. They are copied from the test graphs of the upstream authoring tool, `KhronosGroup/glTF-InteractivityGraph-AuthoringTool`.

## Build and run

There is nothing to build. A runtime under test loads a sample and runs it.
